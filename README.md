# 2026 K-뷰티 산업 지형도 v4

V3에 산업 분석 화면을 추가한 버전입니다.

- 2025 별도매출 TOP 5
- 2024→2025 성장률 TOP 5
- 산업군별 2024/2025 비교 차트
- 기업 클릭 상세정보
- 2025/2024 별도매출
- 증감률
- 브랜드/해외시장/메모
- 기업 추가·수정·삭제
- 검색·산업군 필터
- Excel 불러오기/저장
- PDF 출력
- 브라우저 자동 저장

## 실행
npm install
npm run dev

## 데이터 원칙
공시에서 별도매출을 확인하지 못한 기업은 0으로 두고 추가 확인 필요로 표시합니다. 연결매출을 별도매출로 임의 대체하지 않습니다.
